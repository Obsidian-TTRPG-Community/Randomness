# 09 - Going Further

You know the essentials. Here's what else is in the box.

## The full reference

Click **Settings → Randomness → Open reference**. It's one long
page holding every single thing Randomness can do, and you can
search it. Think of it as this guide, all grown up.

## Portraits

Randomness can draw a random character's face and roll them a
name to go with it. First you need the pictures: open **Settings
→ Randomness**, scroll to **Install Fantasy Portrait Pack**, and
click the **Install** button next to it.

Then put a block like this in any note (indented here so you can
see it, just like the one in chapter 07 — type yours against the
left edge):

    ```portrait
    ```

Or open the sidebar (the 🎲 icon on the left) and use the
**Portraits** and **Builder** tabs. Sizes, seeds, packs, inline
faces mid-sentence, and locking a portrait forever all have their
own chapter: [[10 - Portraits]].

## Fantasy Hub

A big free sample pack: generators that build whole towns, plus
ready-made templates for Templater — that's another Obsidian
plugin, for people who like notes that fill themselves in. Get it
from **Settings → Randomness → Install Fantasy Hub content**.

## Scripting (for the code-curious)

This bit is for people who write a little JavaScript — skip it
happily if that's not you. Other plugins and Templater scripts
can roll your tables through this:

```text
app.plugins.plugins["randomness"].api
```

Roll a whole NPC into a brand-new note from a template — see
[API.md](https://github.com/Obsidian-TTRPG-Community/Randomness/blob/main/API.md)
for everything it can do.

## Twenty years of tables

`.rdm` files use a format called Inspiration Pad Pro. People have
been writing generators in it for about twenty years, and every
one of them opens in Randomness without you changing anything
(`.ipt` files too — that's the older file ending).

For a curated pile of them, click **Settings → Randomness →
Browse community generators**. Or search the web for "inspiration
pad" tables and drop the files into your Generator root folder.

That's the tour. Go roll something. 🎲
