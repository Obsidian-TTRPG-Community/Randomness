## 5. Testing method that keeps finding the bugs

Load the REAL vault notes into an in-memory source and roll every span
regex-scraped from them. This caught every corpus bug this session:

```ts
import { inMemorySource } from "../src/resolver/fileResolver";
import { buildInlineBundle } from "../src/resolver/scope";
import { Evaluator } from "../src/engine/evaluator";
import { translateDiceExpression } from "../src/compat/diceCompat";
// read both notes, inMemorySource({path: content, ...}),
// basenameResolver = case-insensitive, strip .md from the ref;
// for (const m of text.matchAll(/`dice:([^`]*)`/g)) → translate →
// buildInlineBundle → new Evaluator(main, extras, {seed}).run()
// → flag anything matching /\[error:|`dice:/ in the output.
```

Caveats learned the hard way:

- **The jest harness bypasses the async prefetch layer.** A repro that
  passes there can still fail live — the `extraUses` bug was exactly
  that. `__tests__/resolver/asyncPrefetcher.test.ts` covers the seam.
- **Live Preview = partial containers + null `getSectionInfo()`.**
  Test that shape for anything occurrence-based
  (`__tests__/views/unlockTargeting.test.ts` is the model).
- **Animation and result must be the same roll**; never animate from
  the render path; never `MarkdownRenderer` inside results (recursive
  rollers + broken lock targeting).
- These corpus notes are gold. Consider vendoring them (with
  permission) as fixtures.

## 7. Repo facts a newcomer needs

- Docs pipeline: `docs/reference.md` → `npm run embed-reference`;
  `docs/guide/` → `npm run embed-guide`. Never hand-edit the generated
  `src/views/*Content.ts`.
- Architecture: engine (pure) ← resolver ← compat ← views (only layer
  importing Obsidian). Resolver may import compat (compat only
  imports engine).
- `main.js` at repo root is a committed build artifact — rebuild and
  commit it with releases.
- Before any release commit: sweep every tracked text file for NUL
  bytes (a file-sync fault this session put NUL padding INSIDE
  committed README/CHANGELOG, and once corrupted `.git/index` —
  `rm .git/index && git reset` repairs that safely).
- Obsidian review-bot rules honoured in this codebase: no `as any`,
  no `innerHTML` assignment, `window.*` timers, no `window.prompt`
  (Electron blocks it — use a `Modal`), sentence-case UI text.
